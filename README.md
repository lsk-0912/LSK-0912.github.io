# 个人知识库

这是一个基于 GitHub Pages 的个人知识管理系统，用于记录和整理工作与生活中的各类笔记、文档和心得体会。

## 📚 内容结构

### 工作板块
- **项目管理**：项目规划、风险管理、团队协作
- **会议记录**：重要会议的讨论要点和决策
- **技术文档**：技术架构、代码规范、最佳实践

### 生活板块
- **阅读笔记**：书籍、文章的读书笔记和思考
- **个人感悟**：生活感悟、思考总结
- **实用工具**：效率工具、方法、资源整理

## 🚀 特性

- ✅ 纯静态 HTML/CSS/JavaScript 实现
- ✅ 简洁现代的设计风格
- ✅ 响应式布局，支持移动端
- ✅ 本地搜索功能
- ✅ 分类筛选
- ✅ 时间轴归档
- ✅ 快速加载

## 🛠️ 技术栈

- HTML5
- CSS3 (原生 CSS，无预处理器)
- Vanilla JavaScript (无框架依赖)
- GitHub Pages 托管

## 📝 如何添加新笔记

1. 在对应目录（`work/` 或 `life/`）创建新的 HTML 文件
2. 使用现有笔记作为模板
3. 在相应的 index.html 中添加笔记卡片
4. 在 `assets/js/main.js` 的 searchData 中添加搜索索引
5. 提交并推送到 GitHub

## 🎨 自定义

可以通过修改 `assets/css/main.css` 中的 CSS 变量来自定义主题：

```css
:root {
    --primary: #8b5cf6;
    --secondary: #ec4899;
    --text: #1f2937;
    --bg: #ffffff;
}
```
